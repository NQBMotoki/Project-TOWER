# Project TOWER 世界观设定

*内部设定稿 · 含剧情真相*

## 玩家抵达时

旧王国的疆土遍布遗迹。那座塔却几乎无损地立在原处，周围环绕着一股来历不明的力量。直到今天，人们仍在猜测塔门里面有什么。

十年前，一支四人小队从这里进入塔楼，从此杳无音信。有人说他们都败给了塔里的怪物。也有路人说，半夜经过塔前，偶尔会见到几道模糊的人影。那些人影有时在营地旁俯身，像是在整理行装，下一刻却突然转身，仿佛有什么东西扑了过来。目击者也说不准那是不是鬼魂。

## 旧王国的覆灭

百余年前，旧王国派一位领主率下属驻守这座塔。最早的驻防令和领主亲笔信记的是日常事务。谁负责换岗，谁核对出入名册，哪个值夜人需要多领一罐灯油。领主的笔迹和措辞都留在这些文书里。

距今约八十年，王廷的宫廷魔法师施展禁忌黑魔法，唤来邪恶力量和怪物大军。怪物席卷整个旧王国。王国的精锐与宫廷魔法师鏖战，最终杀死了他，自己也在那场战斗中覆灭。王国失去了精锐，没能挡住灾难。从异变发生到旧王国灭亡，还不到一年。

宫廷魔法师死后，魂魄夺取了塔中领主的身体。他继续使用领主的名字，能施展的魔法却远不及生前。此后他藏身塔中，重新钻研黑魔法，靠一次次试验积蓄力量。他打算再次召来怪物大军，将整片大陆永远置于自己的统治之下。

## 十年前的四人小队

骑士、弓箭手、牧师和法师结伴进塔。四人留下的记录从行装、路线和见闻写起，越往上越集中到同一个疑点。旧王国灭亡前后，塔里署着领主名字的文书发生了变化，同一个署名下逐渐出现了与当年灾变有关的法术研究。

小队已经快查明领主身上发生了什么，最后却倒在被夺舍的领主面前。塔前现身的蓝色骑士幽灵正是队里的骑士。他仍记得塔前两件武器的位置。来访者空手靠近塔门时，他会现身，为来访者指出还没拾取的武器。

## 两方留下的文字

### 冒险小队

骑士从队伍出发前的行装册写起，先清点同伴和装备。牧师在祷文里记下谁开始睡不安稳、谁在半夜听见了声音。弓箭手习惯观察射线和退路，先注意到三层的箭孔都朝里。法师则把早年的驻防文书和塔里现存的研究笔记放在一起读，逐渐把怀疑指向领主。四人的记录一道指向领主，到了最接近真相的地方却戛然而止。

### 旧王国的驻塔者

下属的军报记录怪物推进、精锐出战和迟迟等不到回音的过程。夺舍前的领主在亲笔信里操心的是岗哨能否交接、值夜的人是否平安回来。夺舍后的研究笔记仍署着相同的名字，写的却成了法术试验、力量恢复和下一次召唤需要积攒的条件。玩家可以把前后两份字迹、措辞和记录用途放在一起看，再用小队的发现补上这段历史。

塔顶保留灯、门楣刻痕和名册。旧日的信件里，灯为交班的人照路，名册记谁出了塔、谁该回来。到了「灯前留言」，这些熟悉的物件也成了追查小队去向和守塔人身份的线索。
