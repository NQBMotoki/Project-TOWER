# Project TOWER 游戏设计文档

**游戏版本 0.2.0 · 开发候选**

Godot 4.7.2 · Windows x86_64 与 macOS 通用架构 · 简体中文与美式英语

Project TOWER 是一款单人 2D 俯视角动作 Roguelite。玩家在古塔外找到剑和法杖，靠观察预警与利用掩体闯过五层，边战斗边搜集和换装。十年前失踪的小队与旧王国的驻塔者都留下了记录，玩家可沿着两条线索追查古塔的秘密。

## 体验目标

- 约 30 秒理解移动、瞄准、攻击和互动。塔门和塔前拾取点引导玩家掌握初始操作。
- 敌人的预警先于攻击。玩家能通过辨认起手、横移、穿过掩体间的通道和把握收招时机减少受伤。
- 四次清场奖励与怪物掉落带来当局取舍。装备槽限制鼓励按战况换装，固定材料让首次尝试合成成为可能。
- 典型通关目标为 8–12 分钟。用独立试玩者的完整局和各层耗时校准难度与时长。阅读为可选探索，尾声由玩家主动打开。

当前版本使用键鼠、六个装备槽、四类普通敌人和一名守塔精英。场景、角色、动效及声音使用程序绘制或合成，文字使用随包提供的 Noto Sans SC。

## 单局流程

| 阶段 | 玩家体验与推进条件 |
| --- | --- |
| 主菜单 | 开始新局、设置、退出。有可恢复存档时显示继续，新局需要确认覆盖。 |
| 塔前 | 搜索塔门两侧的起始剑和法杖，拾取即装备。两件齐全后可进塔。第一次缺武器尝试进门时，蓝色骑士幽灵现身并指向缺失的武器，演出结束后保留指引。 |
| 楼层揭示 | 播放淡入和标题演出，显示双语玩法提示。F5 另有门楣刻字。至少停留 2.1 秒后才可确认开战。 |
| 战斗 | 清理波次。柱子与碎墙同时影响移动、弹体和攻击视线。可在战斗中拾取或打开背包，打开面板时冻结战斗。 |
| 清场探索 | 清除残余弹体，开放安全拾取和阅读。F1–F4 按继续进入三选一，F5 按继续阅读尾声。 |
| 奖励与上楼 | F1–F4 各选一张卡，物品进入背包，随即进入下一层揭示。装备须在背包穿戴才生效。 |
| 尾声与结算 | 在 F5 清场后打开「灯前留言」，关闭后胜利。HP 归零时失败。结算显示到达层数、击杀、游戏内用时和收集的装备，可重开或返回。 |

默认 WASD 移动，鼠标瞄准，左键剑击，右键施法，E 互动，B 背包，Q 使用绑定的药水，Enter 继续。Esc 关闭最上层面板，或打开暂停。设置可重绑其余键鼠操作，Esc 固定。完整启动与操作说明见 [README](../README.md)。

## 战斗与楼层

剑击是近距离扇形攻击，可同时命中多个目标。魔法有较长冷却，用于远程输出。友方与敌方弹体各自命中对方，掩体阻挡双方弹体和隔墙近战。史莱姆先鼓胀再突进，虚脱时可追击。哥布林停步前摇，骷髅法师咏唱后发射法术球，骷髅弓手以拉弦预警、远程箭矢和近身短刃施压。守塔精英先显示扇形预警再发射散射弹。

| 场景 | 战斗与路线 | 叙事线索 |
| --- | --- | --- |
| 塔前 | 取齐两种武器。营地附近可找材料和书刊。 | 骑士行装册、旧王国驻防令和营地传闻。 |
| F1 | 两波，4 个掩体。通过史莱姆和哥布林练习走位与读招。 | 领主亲笔信。另有固定的合成材料。 |
| F2 | 两波，5 个掩体。用混合近战检验第一件奖励。 | 驻塔军报、牧师的祷文。 |
| F3 | 两波，6 个掩体。首次面对骷髅法师与弓手的远程压力。 | 弓箭手的手记。 |
| F4 | 两波，7 个掩体。四类普通敌人组合出场。 | 法师的调查手记、领主的研究笔记。 |
| F5 | 一波，3 个掩体，中央留空。击败精英即终止战斗，清除幸存小怪与残弹。 | 开场门楣刻字，清场后先探索，再主动打开「灯前留言」。 |

同一局的掩体、波次掉落和待选奖励可随档恢复。书刊拾取时打开，之后可在背包重读。废弃营地提供原地阅读。角色身份和线索编排见[世界观设定](worldbuilding.md)。

## 装备与补给

八件可获取装备分为近战、魔法、手套、饰品、护甲和鞋六槽。每槽只穿戴一件，替换时旧装备留在背包，卸下替代武器会换回起始武器。换装不重置攻击冷却。骑士铠甲提高生命上限，卸下时当前生命最多保留到较低的上限。

每个实际被击败的敌人至多掉一件物品。初始概率为 55% 无掉落、20% 蘑菇、15% 水瓶、10% 装备。准备本波掉落时装备池耗尽，装备档位改为治疗药水。楼层三选一从未持有装备中抽取，不足时按治疗药水、蘑菇、水瓶补齐。同类材料和药水可堆叠，装备和书刊按唯一 ID 持有。

背包内用蘑菇和水瓶各一份合成一瓶治疗药水。塔前和 F1 清场各提供蘑菇和水瓶各一份。药水恢复 30 HP，满血时不消耗，可在背包使用或绑定到快捷栏。

## 界面、本地化与续档

HUD 提示生命、魔法冷却、楼层、波次、剩余敌人和可互动对象。背包提供穿戴、书刊重读、合成与药水快捷栏。奖励卡展示物品和效果，结算记录收集成果。长篇书刊支持滚动，按键提示跟随当前绑定。双语用词、字符串规则和审校流程见[本地化规范](localization.md)。

主菜单与暂停菜单共用设置。语言、键鼠绑定、画质和总音量／音效音量随设置保留。两档画质都显示关键预警和演出，高画质增加环境粒子和装饰光效。暂停或打开面板会冻结战斗、演出和游戏内计时。

单局存档保留塔前、楼层揭示、清场探索、领奖和尾声等阶段。战斗中保存后从本波开战前继续，本波的用时、受伤、击杀、拾取、换装、合成和消耗一并回退。两波之间保存保留已完成波次。主档不可用时尝试同一局的有效备份，胜负结算清除主档与备份。状态与存档接口见[技术架构](architecture.md)。

## 当前验收范围

Engineer 先做 Godot 无头导入和候选回归，再按同一源码基线导出两端候选包。QA 用将要交付的包走完塔前到结算，验证胜负、续档、语言与重绑、不同窗口尺寸、关键预警和听感。独立试玩记录是否理解换装、每层耗时、死亡或卡点，以及总时长。双语负责人确认源文、译文和术语后更新审校状态。

PM 确认版本、双平台包、操作说明、演示及素材许可。测试记录、排期与模块细节见[项目协作文档目录](https://docs.qq.com/sheet/DT2t0WEdBd3RGcFFz?tab=BB08J2)。
