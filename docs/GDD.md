# Project TOWER 游戏设计

开发候选 0.4.0-dev · 本轮改版基线 0.3.0

玩家在塔前装备一把武器，穿过十层古塔。前九层的楼梯在清场后开放，玩家决定何时收取血珠、阅读、换装和上楼。F10 的魔化领主倒下后，玩家仍能探索，亲手触摸水晶才进入尾声。

## 流程与楼层

| 区段 | 战斗与探索 |
| --- | --- |
| 塔前 | 帐篷和篝火构成废弃营地，石路通向塔门。空手与门互动时，玩家后撤，骑士幽灵依次指向剑和杖。直接找到武器也能入塔。拾取第一把武器自动装备，另一把可带走。 |
| F1–F4 | 依次认识史莱姆突进、哥布林近身挥击、骷髅法师咏唱和骷髅弓手拉弦。 |
| F5 | 一场两阶段守关战。精锐骷髅以连斩、扇扫和贴地冲锋轮换施压。闸轨、绞盘座和低位暖灯构成驻地。 |
| F6–F7 | 鬼魂显形、腐蚀史莱姆拖出危险地面、腐蚀哥布林追击。墙脚污痕和拖痕预示变化。 |
| F8–F9 | 腐蚀法师施放延迟咒印，腐蚀弓手分段拉弦连射。残缺咒印和折箭将楼层主题延伸到地面。 |
| F10 | 领主独自开口，随后展开三阶段战斗。破裂王印和顶端水晶提示场地前方。战后可拾取「灯前留言」，靠近水晶按互动键，依次进入坍塌、天际线、字幕和结算。 |

所有可玩区域使用六边形边界、局部视野和同一套掩体规则。近战和弹体可以击碎瓶罐，玩家和敌人都可触发箭板。先出现方向预警，再射出可被实体掩体挡住的箭。清场探索也遵循受伤规则。

祭坛的灰石、棱边受光与像素尺度贯穿塔内建筑。普通楼层沿北墙拱道上楼，首次入塔和抵达塔顶用纵向塔剖面显示位置。战斗清场后配乐收束，探索时可以通过火声和祭坛的短乐句感知方向。

## 成长与发现

- 玩家用同一个输入攻击，持剑近战、持杖远程。每把武器各自计算冷却，切换回来仍有剩余冷却。手套、饰品、护甲和鞋用各自槽位。
- F1–F9 每层清场凝一颗血珠。吸收增加余额。打开魔化页后确认消耗，才能提升物攻、魔攻、最大生命、移速、暴击、攻击间隔／魔法冷却之一。
- 前九次上楼各选一张腐化牌，效果持续到本局结束。牌池包含数值和机制两类。首次上楼播放紫色能量接触演出。
- 背包含物品与穿戴，合成用蘑菇和水瓶制成治疗药水。拾取和发现给出简洁提示，文稿正文由玩家主动打开。
- 局内和主菜单都能访问图鉴。发现和已读独立于单局，领主身份随玩家读过的早期文书和后期研究揭示。

## 候选验收

十层真人整局记录各层战斗、行走、阅读和菜单用时，并观察玩家对来箭方向、血珠取舍、F5 与 F8 压力变化和塔顶出口的理解。实机按实际候选包记录 Windows x86_64、Apple Silicon 和 Intel Mac 的启动、键位、双语、声音、领珠、换装、合成和终点前续档。
