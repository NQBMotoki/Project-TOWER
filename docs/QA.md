# MVP 验证记录

验证环境：macOS / Apple M1，Godot 4.7.2 stable。Windows 运行环境目前不可用。

- 执行 Godot 无头资源导入；资源导入完成。沙箱环境中系统证书读取和编辑器全局设置保存产生环境提示，不影响项目资源写入。
- 执行 `tests/test_mvp.gd`：440 项检查通过。覆盖双语键值、变量与语言保存，剑击及弹体命中、伤害免疫、敌人预警与弹幕、八种装备叠加与数值上限、五层波次和奖励、F1/F3 阅读与跳过、胜利、失败及重新开始。五层流程通过测试驱动推进，不等于真人完整通关。
- Godot 窗口中检查中英文主菜单、奖励卡与记录面板；实际点击奖励卡并检查强化结果，验证 E、Esc、Enter 的阅读行为，检查失败结算界面。
- 使用 Godot 4.7.2 官方模板导出 Windows x86_64 与 macOS 通用架构。两份压缩包通过 ZIP 完整性检查，两个语言资源、字体及许可证均在资源包中。macOS 应用通过 ad hoc 签名完整性检查，启动独立窗口显示主菜单；Windows 包尚未在 Windows 设备运行。
- macOS 导出仅为临时签名，未经过 Apple 公证。分发给其他设备前需按发布要求处理签名、公证及启动验证。
