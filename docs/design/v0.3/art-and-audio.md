# 美术与音频制作

Project TOWER · v0.3 · [GDD 第 7 章](../../GDD.md#art-and-audio)

记录视觉风格、战斗反馈、美术生成与整理、音效制作和素材交接要求。

## 7.1 视觉风格与战斗动效

统一轻像素地下城风格。石材、暗墙和地面细节保持相对低对比，用楼层色调、光源及地标区分进度。F1 用于验证画面规范，F3 将可读记录与背景装饰区分，F5 用视觉焦点提示精英战。全塔沿用同一场地边界。

玩家和四种敌人依靠剪影、体量或动作区分。友方魔法、敌弹及预警用形状、轮廓或方向辅助辨识。挥剑弧与扇区同步，命中出现短闪或小粒子，弹体可加短尾迹。限制高密度特效的数量与停留时间，确保预警、血条和弹道清楚。玩家受伤及时更新血条，敌人死亡与领奖各有短反馈。

## 7.2 AI 生图与美术整理

A 先和 B 定好俯视角、像素比例、色板、画布尺寸及导入规格。用生图模型生成同风格的场景部件、角色与敌人、面板装饰和装备图标，先交付用于 F1 的小批样件。长动画可用少量关键帧和 Godot 动效完成。

A 筛选生成结果，手动清理背景、边缘、噪点和多余细节，对齐角色脚点与帧间位置，再以透明 PNG 或适合场景的 PNG 交付。原生界面渲染双语文字。B 检查实际游戏尺寸下的纹理过滤、对齐和碰撞范围，C 检查实机辨识度。通过 F1 样板后沿用同一套规范扩展到后续楼层。

## 7.3 音效生成与混音

A 优先试用能输出音频的生成模型制作短游戏音效，按事件逐条试听和筛选。生成版进入项目之前，剪掉空白和爆音，处理起收声与音量差，按和 B 约定的规格交付 WAV。现有程序合成音可用作替补，也可分层调音。先保证关键提示清楚，环境氛围和配乐按余量安排。

| 事件 | 声音与接入要求 |
| --- | --- |
| 剑击挥空与命中 | 两类声响可分辨。同一挥砍击中多个目标时，合并或限制重复播放。 |
| 玩家与敌方施法 | 使用可区分的声音，配合弹道外观和方向。精英方向预警可配短提示。 |
| 受伤、死亡与领奖 | 各有独立音效，危险和受伤优先于普通命中。声效配合可见反馈一起传达关键信息。 |

B 在既有攻击、命中、受伤、死亡与领奖事件上接入，设置同类并发限制和混音层级。C 用 Windows 和 macOS 的独立包试听，检查密集战斗及连续按键时关键声音是否清楚，并核对录制成片中的游戏音。

## 7.4 素材交接

A 为采用的资源交付可导入成品、对应场景或事件、规格、预览与来源记录。来源记录包括工具或模型、生成日期、可追溯的生成记录、参考素材来源，以及实际适用的使用与再分发条款和署名。

B 按清单导入并回传可玩包，核对贴图、帧、触发时机及混音。C 按版本反馈问题。缺少可分发成品时，先采用现有绘制或合成资源，保留敌我、伤害与预警的辨识度。
