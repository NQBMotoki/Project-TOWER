# 战斗与敌人

Project TOWER · v0.4 · [GDD 第 3 章](../../GDD.md#combat-and-enemies)

记录玩家基础属性、命中规则、敌人数值、敌人行为和预警要求。

## 3.1 玩家属性与命中规则

| 属性 | 初始值 | 判定与反馈 |
| --- | --- | --- |
| 生命与移动 | 100 HP，185 px/s | 受伤后有 0.6 秒无敌，血条与受击反馈同步。HP 归零触发失败。 |
| 剑击 | 12 伤害，间隔 0.42 秒 | 朝鼠标挥剑，基础半径 60 px、扇区 100°。判定计入敌人碰撞半径，可对扇区内多个敌人造成伤害及击退。 |
| 魔法弹 | 20 伤害，冷却 2.4 秒 | 沿瞄准方向直线前进，基线弹速 400 px/s。命中首个有效敌人、出界或到达生命周期时消失。 |
| 暴击 | 概率 5%，伤害倍率 150% | 剑击逐目标掷出结果，魔法在发射时计算伤害。 |

近战适合近距离清群，魔法用于拉开距离后输出。友方弹体只打敌人，敌弹只打玩家。弹体使用轨迹线段进行命中检测，一次命中后即消耗。敌人出生时显示提示，并短暂延迟攻击，玩家能据此准备走位。

## 3.3 敌人行为与应对

| 敌人 | 行为与应对 |
| --- | --- |
| 史莱姆 Slime | 四段循环：蠕动逼近 38 px/s；进入 150 px 后鼓胀 0.75 秒并锁定方向，地面出现楔形预警；突进 400 px/s 约 80 px；虚脱 0.55 秒，此阶段不能造成伤害。接触伤害在蠕动、鼓胀、突进均生效，虚脱是唯一的惩罚窗口。侧移可躲开突进，虚脱期贴身输出。 |
| 哥布林 Goblin | 追击后停步，锁定方向并前摇 0.5 秒再挥击。根据预警移出攻击范围。 |
| 骷髅法师 Skeleton Mage | 保持中距离，太近时退后，太远时靠近。咏唱 0.55 秒（身侧一圈警示环逐渐补满）后发射单枚敌弹，迫使玩家横向走位。咏唱期间原地不动，是读招窗口。 |
| 骷髅弓手 Skeleton Archer | 维持 240–360 px 距离带，近于 170 px 时后退，且后退期间不能射击。拉弦 0.8 秒：一条虚线从弓指向玩家并逐渐变实，方向在拉弦瞬间锁定，之后不再追踪。释放后进入 2.2 秒冷却，期间只走位不攻击，这是惩罚窗口。箭速 560 px/s，约为玩家移速三倍，**跑不掉，只能横向闪避**。 |
| 守塔精英 Elite Skeleton | 在 F5 发射三枚散射弹。v0.4 补齐 0.75 秒方向预警：扇形警示与瞄线先于弹体出现，玩家可在预警阶段选择走位路线。 |

史莱姆的虚脱、法师的咏唱、弓手的换弦，三者构成同一套"看前兆、等窗口"的语言；精英的扇形警戒是这套语言的收束。

## 3.4 生成与节奏

同一波敌人的出生等待为 `0.85 + 0.35 × 序号` 秒，逐只叠加，出生环随进度收拢。生成期间敌人不移动、不攻击，避免四只敌人同帧起手造成叠加伤害。
