# 战斗与敌人

Project TOWER · v0.3 · [GDD 第 3 章](../../GDD.md#combat-and-enemies)

记录玩家基础属性、命中规则、敌人数值、敌人行为和精英预警要求。

## 3.1 玩家属性与命中规则

| 属性 | 初始值 | 判定与反馈 |
| --- | --- | --- |
| 生命与移动 | 100 HP，185 px/s | 受伤后有 0.6 秒无敌，血条与受击反馈同步。HP 归零触发失败。 |
| 剑击 | 12 伤害，间隔 0.42 秒 | 朝鼠标挥剑，基础半径 60 px、扇区 100°。判定计入敌人碰撞半径，可对扇区内多个敌人造成伤害及击退。 |
| 魔法弹 | 20 伤害，冷却 2.4 秒 | 沿瞄准方向直线前进，基线弹速 400 px/s。命中首个有效敌人、出界或到达生命周期时消失。 |
| 暴击 | 概率 5%，伤害倍率 150% | 剑击逐目标掷出结果，魔法在发射时计算伤害。 |

近战适合近距离清群，魔法用于拉开距离后输出。友方弹体只打敌人，敌弹只打玩家。弹体使用轨迹线段进行命中检测，一次命中后即消耗。敌人出生时显示提示，并短暂延迟攻击，玩家能据此准备走位。

## 3.3 敌人行为与应对

| 敌人 | 行为与应对 |
| --- | --- |
| 史莱姆 Slime | 持续追近，在接触范围内造成周期伤害。拉开距离或用剑击退。 |
| 哥布林 Goblin | 追击后停步，锁定方向并前摇 0.5 秒再挥击。根据预警移出攻击范围。 |
| 骷髅法师 Skeleton Mage | 保持中距离，太近时退后，太远时靠近。发射单枚敌弹，迫使玩家横向走位。 |
| 守塔精英 Elite Skeleton | 在 F5 发射三枚散射弹。v0.3 增加方向预警和出弹前摇，玩家可在预警阶段选择走位路线。 |

表中数值为五层初始配置的调试起点。Engineer 根据试玩调整配置，QA 回归行为、可回避性和反馈。精英预警必须先于弹体实际生成，方向与弹道一致。

敌人数值调整时，Engineer 同步核对 [`data/game_data.gd`](../../../data/game_data.gd) 中的 `ENEMIES` 配置。
