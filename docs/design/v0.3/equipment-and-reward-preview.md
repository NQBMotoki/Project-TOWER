# 装备与奖励预览

Project TOWER · v0.3 · [GDD 第 5 章](../../GDD.md#equipment-and-reward-preview)

记录装备池、抽取和叠加规则、数值限制及奖励预览的行为。

## 5.1 装备池与叠加

每次奖励从八件装备中等概率抽取三件，单次抽取互不重复。装备选中即应用，可跨层再次出现并叠加，最多领取四次。重复选择同一张卡或快速双击只应用一次。

| ID | 装备名称 | 每次选择的效果 |
| --- | --- | --- |
| U01 | 锋利长剑 Sharpened Longsword | 剑击伤害 +6 |
| U02 | 疾风手套 Swiftwind Gloves | 剑击冷却乘 0.8，最低 0.22 秒 |
| U03 | 烈焰法杖 Flame Staff | 魔法弹伤害 +12 |
| U04 | 奥术戒指 Arcane Ring | 魔法冷却乘 0.75，最低 1.0 秒 |
| U05 | 幸运徽章 Lucky Emblem | 暴击率 +15%，最高 60% |
| U06 | 吸血剑刃 Lifedrinker Blade | 每次剑击击杀额外恢复 5 HP，回复量叠加 |
| U07 | 骑士铠甲 Knight's Armor | 最大 HP +25，同时恢复 25 HP |
| U08 | 迅捷长靴 Swift Boots | 移动速度乘 1.15 |

伤害和固定回复量按次累加，速度与冷却按次相乘并应用相应限制。回复最多达到当前最大 HP。玩家可用剑伤、剑击频率和击杀回血强化近战，用法伤或魔法冷却强化远程输出，也可选血量、移动速度或暴击补足当前打法。

## 5.2 强化预览

v0.3 的奖励卡同时展示名称、图标、明确效果、当局强化预览与叙事短句。直接属性显示「当前值 → 选择后值」，冷却下限与暴击上限显示实际结果并提示触顶。铠甲分开展示最大 HP 与即时回复，吸血注明剑击击杀触发和每次回复量。

预览和选择共用同一套强化计算。预览只读，确认后的实际属性和结算记录与预览一致。双语共用相同数值与格式变量。

前四层清场后按 Enter 可查看奖励卡。`Reward` 下每张卡的 `IconPlaceholder` 是 56 × 56 像素的装备图标挂点。素材接入前，卡片通过 `ITEM_*_BADGE` 显示中英文效果短标签。
